# ⌨️ Typing Speed Test

A simple Typing Speed Test application built with **HTML, CSS, and JavaScript**. The timer starts automatically when you press your first key, giving you a realistic typing test experience while providing instant feedback on your accuracy.

## ✨ Features

* ⏱️ Automatic timer that starts on the first keystroke.
* 🎯 Live typing validation.
* 🟢 Green border when the text is completed correctly.
* 🟡 Yellow border while your typing matches the target text.
* 🔴 Red border when a mistake is detected.
* 🔄 Restart button to reset the test.
* ✏️ Change the test text to any custom paragraph.
* 🔒 Lock the custom text before starting a new test.
* ⌛ Timer displayed in **minutes : seconds : hundredths of a second (MM:SS:HH)**.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla)

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/typing-speed-test.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

No additional dependencies or installation are required.
